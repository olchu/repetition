# Предметы и иконки

Единый справочник в коде: `src/lib/subjects.ts`.

Имена файлов `phisics.png` и `spain.png` намеренно сохранены.
Прежние `science` и `history` поддерживаются для совместимости с существующими тестами;
для них используется стандартная иконка книги, поскольку отдельные изображения не предоставлены.

Предметы назначаются **отдельно от тестов**, в Children → Subjects → Save subjects.
`ChildProfile.subjects` хранит список предметов. Новые и существующие ученики без явных
назначений имеют пустой список; миграция не выводит назначения из тестов.
API создания/изменения ученика принимает `subjects` — массив ID из справочника;
пустой массив снимает все назначения, отсутствие поля сохраняет прежние назначения.
Дашборд показывает только назначенные предметы, даже если по ним пока нет тестов.
Назначенные тесты и результаты сохраняются независимо от списка предметов.

При изменении справочника синхронизировать Prisma enum и `docs/test.schema.json`.
